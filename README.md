# Agreement Maker (PWA)

PWA-конструктор договорів з каталогу перевірених клауз. Інтерфейс і дані українською, підтримка ролей та версіювання.

## Можливості
- Каталог пунктів з пошуком за текстом і тегами, історією версій та коментарями.
- Ролі: співробітник, юрист, адміністратор із можливістю швидкого перемикання у хедері.
- Статуси пунктів: створено → перевірено юристом → визнано типовим / одноразово погоджено.
- Конструктор договорів із підбором лише перевірених/типових пунктів, версіями та ручними статусами.
- Коментарі та журнали версій для пунктів і договорів.
- Базова аналітика: статистика статусів, популярні клаузи, середня тривалість погодження.
- PWA: манифест, сервіс-воркер та кешування shell.

## Запуск
Через обмеження середовища залежності не встановлені автоматично. Для локального запуску:

```bash
npm install
npm run dev
```

Для продакшн-збірки:

```bash
npm run build
```

Сервіс-воркер реєструється автоматично після завантаження сторінки.
